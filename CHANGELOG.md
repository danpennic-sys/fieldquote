# Changelog

All notable changes to the FieldQuote asset pack.

## [1.0.0] — 2026-10-02

### Added
- 10 trade quote templates (Plumbing, HVAC, Electrical, Landscape, Handyman, General)
- 5 invoice HTML templates (standard, progress, service call, maintenance, change order)
- Service menu example CSV + usage guide
- Customer intake field map
- Job-status board (Kanban) notes
- Command branding config (`branding/config.json`)
- Pricing strategy worksheet (markdown)
- 12-month revenue plan (markdown)
- Customer follow-up scripts
- Quote → close conversion playbook
- Onboarding + annual review call checklists
- PACKAGING.md for Operator / Command zip layouts

### Notes
- Excel and PDF versions of pricing/revenue tools are distributed as release binaries, not in this repo.
