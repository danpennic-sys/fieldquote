# Onboarding Call + Annual Review Checklists

## Onboarding Call (60 min) — Operator / Command

### 0–15 min — Business overview
- [ ] Current monthly revenue (approx)
- [ ] Average ticket size
- [ ] How quotes are done today (paper / text / other software)
- [ ] Biggest pain: speed, professionalism, follow-up, or tracking?

### 15–35 min — Install + first quote
- [ ] Install FieldQuote / confirm app opens
- [ ] Load one quote template for their main trade
- [ ] Create a sample customer + job
- [ ] Generate and preview first real-looking quote
- [ ] Show how to mark Sent → Accepted → Scheduled

### 35–50 min — Pricing worksheet
- [ ] Walk through hourly rate calculation
- [ ] Set minimum trip fee
- [ ] Decide material markup %
- [ ] Note any “never discount” rules

### 50–60 min — Next 30 days
- [ ] Target: quotes to send this month
- [ ] Pick 3 templates to customize
- [ ] Schedule first follow-up check-in (optional)

---

## Annual Review Call (60 min) — Command tier

### Review numbers
- [ ] Quotes sent vs accepted (close rate)
- [ ] Average ticket vs target
- [ ] Revenue vs 12-month plan
- [ ] Top 3 job types by volume

### Adjust
- [ ] Update service menu prices
- [ ] Revisit trip fee / markup
- [ ] Drop or add templates based on actual work

### Next year
- [ ] Set new monthly revenue target
- [ ] Recalculate required quotes/month
- [ ] Agree on one process improvement (e.g. same-day send discipline)
