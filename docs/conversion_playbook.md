# Quote → Close Conversion Playbook

## Goal
Raise close rate without sounding pushy. Same-day quotes + disciplined follow-up.

## Status mapping (FieldQuote)
| Stage              | Status field | Action                                      |
|--------------------|--------------|---------------------------------------------|
| Created on site    | Draft        | Finish line items same day                  |
| Sent to customer   | Sent         | Within 2 hours of leaving the job           |
| Customer says yes  | Accepted     | Lock schedule                               |
| On calendar        | Scheduled    | Confirm day before                          |
| Work done + billed | Invoiced     | Collect or set payment terms                |
| Money in           | Paid         | Request review                              |
| No response 7 days | Lost         | Archive; optional “last chance” later       |

## Cadence
1. **Same-day send** — quote out within 2 hours of site visit.
2. **24-hour follow-up** — one short message (script in followup_scripts.txt).
3. **3-day follow-up** — final reminder.
4. **Day 7** — mark Lost if no response.

## Rules of thumb
- Never discount just to close; offer a clear “book this week” value instead (e.g. priority slot).
- If they ask for a lower price, remove scope rather than cut rate.
- Log every contact attempt in the job notes so the next follow-up is informed.
